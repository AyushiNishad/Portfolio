# Ayushi Nishad — Pro React Portfolio

A polished, responsive React + Vite portfolio created from Ayushi's supplied resume, profile image, links and achievement material.

## Run
```bash
npm install
npm run dev
```
Then open the localhost URL shown by Vite.

## Build for deployment
```bash
npm run build
npm run preview
```

## Deploy
This can be deployed to Vercel, Netlify or GitHub Pages after building/configuring the selected host.

## Main files
- `src/main.jsx` — portfolio content/components
- `src/styles.css` — full responsive design
- `public/assets/` — profile and achievement images
- `public/Ayushi_Nishad_Resume.pdf` — resume download
